# Ravi Patel - Personal Portfolio
===============================

## Folder structure:
  index.html                          -> main page (open this in your browser)
  css/style.css                       -> all styling
  js/script.js                        -> mobile menu, animations
  assets/images/profile-placeholder.svg -> dummy profile photo

## How to run:
  Unzip the folder and double-click index.html.

## How to change your photo:
  1. Put your photo in assets/images/ (for example photo.jpg).
  2. In index.html, find the hero <img> and change
     src="assets/images/profile-placeholder.svg"  to  src="assets/images/photo.jpg"
